# INBA — Plataforma de Comercialización Productiva de Imbabura

Prototipo frontend navegable basado en la interfaz visual aprobada para INBA.

## Visualización
El archivo principal es [index.html](./index.html). Una vez habilitado GitHub Pages, la demo estará disponible en:

https://madeleynplay-dotcom.github.io/inba-plataforma/

## Módulos demostrativos
- Inicio y presentación pública de INBA.
- Marketplace y catálogo de productos.
- Pedidos.
- Productores.
- Compradores.
- Transportistas y logística.
- Inventario.
- Administración.

## Ejecutar localmente
Descargar o clonar el repositorio y abrir `index.html` en un navegador moderno. No requiere instalación ni dependencias externas.

## Alcance y limitaciones
Este repositorio contiene un prototipo de interfaz (frontend) con datos ficticios y operaciones simuladas en el navegador. No incluye backend, base de datos, autenticación real, procesamiento de pagos, notificaciones ni integraciones productivas. No debe utilizarse para transacciones reales.
